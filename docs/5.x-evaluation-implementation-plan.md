## Global Constraints

1. **Branch**: Work directly on `5.x` (`git branch --show-current` must be `5.x`).
2. **Public IP Obfuscation**: Never commit literal full public IPv4 addresses in scripts, tests, or documentation. Always use `x.x.x.138`, `x.x.x.55`, `x.x.x.93`, or placeholders `<PBX_IP>` / `<GEN_IP>`.
3. **Unit Standardization**: Always use decimal storage and memory units (`GB`, `MB`, `KB`) in documentation prose (reserve `GiB`/`MiB` strictly for unformatted command output).
4. **Live Firewall Safety**: Never execute live mutating `nft` commands.
5. **Pint & Cache Discipline**: Run `./vendor/bin/pint --dirty` only when PHP files are modified, and run `tpbx optimize:clear` once after code changes.
