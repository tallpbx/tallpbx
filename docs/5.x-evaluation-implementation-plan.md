## Global Constraints

1. **Branch**: Work directly on `5.x` (`git branch --show-current` must be `5.x`).
2. **Public IP & Key-Path Obfuscation**: Never commit literal full public IPv4 addresses or private-key paths (`ppx2-client`) in scripts, tests, or documentation. Always use `x.x.x.138`, `x.x.x.55`, `x.x.x.93`, or placeholders `<PBX_IP>` / `<GEN_IP>`.
3. **Unit Standardization**: Always use decimal storage and memory units (`GB`, `MB`, `KB`) in documentation prose (reserve `GiB`/`MiB` strictly for unformatted command output).
4. **Live Firewall Safety**: Never execute live mutating `nft` commands.
5. **Verification, Pint, Cache & Parallel Test Discipline**:
   - Run `tpbx optimize:clear` after code/script/config changes.
   - Run `./vendor/bin/pint --dirty` only when PHP files are modified.
   - Always pass `--parallel` when running Pest (`./vendor/bin/pest --parallel ...`).
   - Do not stage `.superpowers/` scratch files when committing; stage explicit target files only.
